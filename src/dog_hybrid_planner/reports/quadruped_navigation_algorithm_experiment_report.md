# 四足机器人导航路径规划方法算法解释与实验报告

## 摘要

针对四足机器人在室内复杂障碍环境中导航时容易出现路径贴近障碍物、全局路径折线过多、局部避障过程中侧向运动过多以及多次重规划后速度下降等问题，本文设计并实现了一种面向四足机器人运动特性的全局-局部融合路径规划方法。该方法以改进 A* 算法生成安全、平滑的全局参考路径，以改进 DWA 算法生成实时局部运动轨迹，并结合四足机器人“头部朝前优先、侧移辅助避障”的运动特点，对速度采样、路径跟踪、头部方向对齐和巡航速度保持进行了优化。实验基于 ROS Noetic/Ubuntu 20.04、Gazebo、RViz 和 ASK-3 四足机器人模型完成，结果表明，所提出方法能够提高全局路径平滑性，减少无意义转向和侧向运动，并改善机器人在多次重规划后的运动连续性。

## 1. 实验目的

本实验的主要目标如下：

1. 验证改进 A* 算法能否生成远离障碍物且弯折较少的全局路径。
2. 验证 DWA 算法能否以 A* 路径作为参考走廊，在机器人周围实时生成局部可行轨迹。
3. 验证四足机器人在空间充足时能否优先以头部朝向运动方向的姿态前进，而不是大量侧移。
4. 验证速度保持机制能否减少多次路径重规划后机器人速度明显下降的问题。
5. 通过 RViz 可视化 A* 全局路径和 DWA 实时局部路径，分析算法规划效果。

## 3. 算法总体框架

本文采用“全局规划 + 局部实时规划 + 四足运动姿态约束”的融合框架。整体流程如下：

1. 地图服务器发布静态栅格地图 `/map`。
2. AMCL 根据激光雷达 `/scan` 和里程计估计机器人在 `map` 坐标系下的位置。
3. 用户在 RViz 中发布目标点 `/move_base_simple/goal`。
4. 改进 A* 根据当前位置和目标点生成全局参考路径 `/dog_global_path`。
5. DWA 在每个控制周期中，根据机器人当前状态、激光雷达障碍物点和 A* 全局路径局部窗口，生成实时局部路径 `/dog_dwa_path`。
6. 导航节点根据 DWA 输出速度、头部方向对齐机制和巡航速度保持机制，发布四足机器人速度命令。
7. `dog_sim` 原始四足控制器执行步态运动。

该框架中，A* 路径不再作为机器人必须严格跟踪的唯一轨迹，而是作为 DWA 的参考走廊；机器人实际执行的路径由 DWA 实时生成。

## 4. 改进 A* 全局路径规划算法

### 4.1 栅格地图建模

环境地图采用二维占据栅格表示。每个栅格状态定义为：

| 栅格值 | 含义 |
| --- | --- |
| `0` | 可通行区域 |
| `100` | 障碍物 |
| `-1` | 未知区域，按障碍物处理 |

由于四足机器人机体具有一定长度和宽度，不能将机器人简化为质点。因此在全局规划前，需要对障碍物进行膨胀处理。膨胀半径记为：

```text
r_inflate
```

当某一栅格距离障碍物小于该膨胀半径时，将其视为不可通行区域，从而避免全局路径过于贴近墙体或障碍物边缘。

### 4.2 安全距离软代价

仅进行硬膨胀会保证路径不碰撞，但路径仍可能贴着膨胀边缘行走。对于四足机器人而言，运动过程中存在身体摆动和步态误差，因此本文进一步引入安全距离软代价。

设某候选栅格到最近障碍物的距离为：

```text
d_obs
```

设软安全距离半径为：

```text
r_clear
```

当 `d_obs < r_clear` 时，对该栅格引入额外代价：

```text
C_clear = w_clear * (1 - d_obs / r_clear)^2
```

其中 `w_clear` 为安全距离权重。该代价使路径倾向于从通道中间穿过，而不是沿障碍物边缘穿行。

### 4.3 转角惩罚

传统 A* 在栅格地图中容易产生频繁的小角度折线。为减少无意义转折，本文在搜索代价中加入转角惩罚项。

设当前节点为 `n`，父节点为 `p`，候选下一节点为 `q`，则前后两段方向向量为：

```text
v1 = n - p
v2 = q - n
```

转角代价定义为：

```text
C_turn = w_turn * (1 - cos(theta))
```

其中 `theta` 为 `v1` 与 `v2` 的夹角，`w_turn` 为转角权重。当路径方向变化越大时，代价越高，从而降低锯齿路径被选中的概率。

### 4.4 综合代价函数

改进 A* 的节点代价函数为：

```text
f(n) = g(n) + W(n) * h(n)
```

其中：

```text
g(n) = g(parent) + step_cost * (1 + C_clear) + C_turn
```

`h(n)` 为欧氏距离启发函数，`W(n)` 为动态权重。综合考虑距离、安全性和转角平滑性后，全局路径不再只追求最短距离，而是更适合四足机器人通过。

### 4.5 视线直连剪枝

A* 搜索得到的原始路径通常包含大量中间节点。本文在路径后处理阶段加入视线直连剪枝。其思想是：

从当前路径点开始，向后寻找最远的可直接连通路径点；如果两点之间的直线段不穿过障碍物膨胀区域，且满足最小安全距离要求，则删除中间节点。

该步骤可以明显减少全局路径中的无意义弯折。

### 4.6 安全圆角平滑

为了进一步提高路径连续性，本文采用 Chaikin 圆角平滑方法处理剪枝后的路径。对于相邻点 `P_i` 和 `P_{i+1}`，生成两个新点：

```text
Q_i = 0.75 * P_i + 0.25 * P_{i+1}
R_i = 0.25 * P_i + 0.75 * P_{i+1}
```

该方法能够将尖锐折角变为更平滑的曲线段。平滑后系统会再次检查路径是否穿入膨胀障碍物区域。若平滑路径不安全，则放弃圆角平滑，回退到视线直连剪枝路径。

因此，当终端出现：

```text
[A*] Corner smoothing unsafe; using line-of-sight shortcut path
```

说明圆角平滑后的路径可能靠近或进入障碍物膨胀区，系统主动放弃该平滑结果，改用安全的直连剪枝路径。这不是规划失败，而是安全保护机制。

### 4.7 路径重采样

为了便于 DWA 使用全局路径作为局部参考走廊，本文对最终全局路径进行固定间距重采样。默认采样间距为：

```text
0.10 m
```

重采样后的路径点分布更加均匀，有利于局部目标点选取和 DWA 轨迹评分。

## 5. 改进 DWA 局部路径规划算法

### 5.1 传统 DWA 原理

DWA 算法根据机器人当前速度和加速度约束，在可达速度空间内采样多个速度组合，并预测短时间内的运动轨迹。每条轨迹根据目标接近程度、障碍物距离和速度大小进行评分，最终选择评分最高的轨迹作为局部运动指令。

传统轮式机器人 DWA 的速度空间通常为：

```text
(v, w)
```

其中 `v` 为前向速度，`w` 为角速度。

### 5.2 四足机器人三维速度空间

ASK-3 四足机器人具有一定侧向移动能力，因此本文将速度空间扩展为：

```text
(vx, vy, w)
```

其中：

| 变量 | 含义 |
| --- | --- |
| `vx` | 机体前向速度 |
| `vy` | 机体侧向速度 |
| `w` | 机体偏航角速度 |

对应运动学模型为：

```text
x_{t+1} = x_t + (vx * cos(theta) - vy * sin(theta)) * dt
y_{t+1} = y_t + (vx * sin(theta) + vy * cos(theta)) * dt
theta_{t+1} = theta_t + w * dt
```

该模型能够描述四足机器人前进、侧移和转向组合运动。

### 5.3 动态窗口约束

在每个控制周期内，DWA 根据当前速度和加速度约束生成动态窗口：

```text
vx_min = max(vx_lower, vx_current - a_max * dt)
vx_max = min(vx_upper, vx_current + a_max * dt)
vy_min = max(vy_lower, vy_current - a_max * dt)
vy_max = min(vy_upper, vy_current + a_max * dt)
w_min  = max(w_lower,  w_current  - alpha_max * dt)
w_max  = min(w_upper,  w_current  + alpha_max * dt)
```

为了减少仿真里程计速度延迟导致的“重规划后速度下降”，本文在安全情况下将上一周期实际发布的速度命令作为辅助速度状态，使 DWA 动态窗口不会因为 `/odom` 的滞后而反复从低速开始采样。

### 5.4 轨迹评价函数

本文 DWA 轨迹评分函数综合考虑以下因素：

| 评分项 | 作用 |
| --- | --- |
| `progress` | 预测轨迹终点是否接近局部目标 |
| `clearance` | 轨迹与障碍物之间的最小距离 |
| `velocity` | 鼓励较高速度，提高实验效率 |
| `heading` | 鼓励运动方向与机体头部方向一致 |
| `path_corridor` | 鼓励局部轨迹靠近 A* 参考走廊 |
| `forward_bias` | 鼓励头部朝前的前向运动 |
| `side_penalty` | 抑制开阔区域内不必要侧移 |
| `side_bypass` | 在障碍物附近允许必要侧向避障 |

综合评价函数可表示为：

```text
Score = a * progress
      + b * clearance
      + c * velocity
      + d * heading
      + e * path_corridor
      + f * forward_bias
      - g * side_penalty
```

当机器人处于开阔区域时，算法倾向于选择前进速度较高、侧移较小、头部方向与路径方向一致的轨迹；当机器人靠近障碍物时，允许使用侧移或后退完成避障。

### 5.5 A* 参考走廊约束

传统局部规划器通常只跟踪全局路径上的某个局部目标点，容易导致路径突变或目标点跳变。本文将 A* 全局路径作为参考走廊传入 DWA，DWA 对每条预测轨迹的中点和终点计算其到全局路径局部窗口的距离。

若预测轨迹越接近全局路径局部窗口，其 `path_corridor` 得分越高。这样机器人实际运动仍由 DWA 实时决定，但不会完全偏离全局规划方向。

### 5.6 DWA 实时局部路径显示

DWA 每个周期会发布当前最优预测轨迹：

```text
/dog_dwa_path
```

RViz 中同时显示：

```text
/dog_global_path  -> A* 全局路径
/dog_dwa_path     -> DWA 实时局部路径
```

其中，A* 路径用于观察全局规划结果，DWA 路径用于观察机器人当前实际准备执行的局部运动轨迹。

## 6. 四足机器人运动姿态适配策略

### 6.1 头部朝前优先机制

四足机器人虽然可以侧向移动，但从实际运动姿态和步态稳定性考虑，主要运动方式应为头部朝前行走。若机器人在开阔区域仍大量侧移，会导致运动姿态不自然，并降低导航效率。

因此，本文设计了 DWA 路径方向对齐机制：

1. 读取 DWA 当前最优局部轨迹。
2. 取前方约 `0.45 m` 处的轨迹方向作为局部路径方向。
3. 计算机器人头部方向与该局部路径方向的夹角。
4. 当夹角大于阈值且周围空间足够时，优先控制机器人偏航，使头部对齐 DWA 路径。
5. 对齐过程中降低侧向速度比例，减少复杂侧移。

该策略不是让机器人重新硬跟踪 A*，而是在 DWA 已经生成局部路径的基础上，让机器人以更符合四足运动习惯的姿态执行局部路径。

### 6.2 侧向运动约束

侧向速度 `vy` 不是完全禁止，而是作为辅助避障动作使用。算法在以下情况下允许较明显侧移：

1. 前方障碍物较近；
2. 局部目标明显位于机器人侧方；
3. 窄通道或墙角附近需要绕行；
4. DWA 无法找到安全前进轨迹。

而在开阔区域中，算法通过 `side_penalty` 和头部对齐机制抑制无意义侧移。

### 6.3 速度保持机制

在仿真中，多次重规划后机器人容易出现速度逐渐下降的问题。原因主要包括：

1. `/odom` 中实际速度存在延迟；
2. 重规划后局部目标点发生变化，DWA 动态窗口从低速重新采样；
3. 头部对齐机制可能短时间压低前进速度；
4. 局部避障评分中过度偏向安全距离，导致速度项权重不足。

为解决该问题，本文加入以下机制：

1. 使用上一周期发布的速度命令辅助 DWA 动态窗口；
2. 成功重规划后设置短时间快速恢复窗口；
3. 开阔直行时设置最低巡航速度；
4. 提高 DWA 速度评分权重和前向运动偏好。

当前主要速度参数如下：

| 参数 | 数值 | 含义 |
| --- | --- | --- |
| `max_vx` | `0.75 m/s` | 最大前进速度 |
| `max_vy` | `0.26 m/s` | 最大侧向速度 |
| `max_omega` | `1.35 rad/s` | 最大偏航角速度 |
| `max_speed` | `0.75 m/s` | 平面速度上限 |
| `min_cruise_vx` | `0.34 m/s` | 开阔直行最低巡航速度 |
| `replan_cruise_vx` | `0.38 m/s` | 重规划后快速恢复巡航速度 |
| `post_replan_fast_grace` | `1.3 s` | 重规划后快速恢复时间 |

## 7. 恢复与安全策略

### 7.1 前方紧急限制

当雷达检测到机器人头部正前方距离过近时，系统不会立即停止所有运动，而是只限制正向 `vx`，保留侧移、后退和转向能力。这样机器人在墙角或窄通道附近仍可通过 DWA 寻找逃离动作。

### 7.2 Recovery 机制

当 DWA 无法找到可行轨迹，或机器人在障碍物附近长时间无进展时，系统进入 recovery。恢复流程为：

```text
后退 -> 小角度旋转 -> 侧步
```

该顺序适合四足机器人在墙角附近脱困，因为先后退可以为机体旋转创造空间，避免原地旋转时尾部或侧边继续贴墙。

### 7.3 Recovery 触发限制

为了避免开阔区域中误触发 recovery，本文限制 `no_progress` 只有在附近存在障碍物或前/侧方向受限时才触发恢复。若周围空间充足，即使短时间目标距离下降不明显，也继续交由 DWA 控制。

## 9. 评价指标

### 9.1 路径长度

路径长度用于衡量规划路径的距离代价：

```text
L = sum sqrt((x_i+1 - x_i)^2 + (y_i+1 - y_i)^2)
```

路径越短，一般表示全局绕行越少。

### 9.2 路径平滑性

路径平滑性通过累计转角衡量：

```text
S = sum |theta_i+1 - theta_i|
```

累计转角越小，路径越平滑，机器人执行时越不容易频繁转向。

### 9.3 最小障碍物距离

记录路径上各点到最近障碍物的距离：

```text
D_min = min d(path_i, obstacle)
```

该指标反映路径安全性。对于四足机器人，较大的最小障碍物距离有利于降低碰撞和卡滞风险。

### 9.4 导航完成时间

从目标点发布到机器人进入目标容差范围所用时间：

```text
T = t_finish - t_start
```

该指标反映导航效率。

### 9.5 平均速度

平均速度定义为：

```text
V_avg = 实际运动距离 / 导航完成时间
```

该指标用于评估速度提升和速度保持机制效果。

### 9.6 侧向运动比例

侧向运动比例定义为：

```text
R_side = sum |vy| / (sum |vx| + sum |vy|)
```

该比例越低，说明机器人越倾向于头部朝前运动；但在狭窄区域中，该指标不应完全为零，因为适度侧移有利于避障。

### 9.7 重规划后速度恢复能力

记录每次重规划后的短时间平均前进速度：

```text
V_replan = mean(vx, t_replan -> t_replan + 1.3s)
```

该指标用于判断机器人是否在多次路径规划后出现明显速度下降。

## 10. 实验过程

实验过程如下：

1. 启动 Gazebo、RViz、地图服务器、AMCL 和导航节点。
2. 等待机器人模型稳定站立，确认 `/scan`、`/map`、`/odom` 和 TF 正常。
3. 在 RViz 中选择目标点。
4. 观察终端输出，确认 A* 成功规划全局路径。
5. 在 RViz 中观察 `/dog_global_path` 和 `/dog_dwa_path`。
6. 记录机器人是否能沿 DWA 局部路径向目标运动。
7. 在墙角、窄通道、长直走廊和多转弯场景分别重复实验。
8. 记录路径长度、导航时间、平均速度、侧向运动比例和是否触发 recovery。

## 11. 实验现象分析

### 11.1 全局路径效果

改进前，A* 全局路径容易出现以下现象：

1. 路径贴近障碍物边缘；
2. 栅格路径折线较多；
3. 局部转角频繁变化；
4. DWA 在执行时需要频繁调整方向。

改进后，全局路径经过安全距离代价、转角惩罚、视线直连剪枝和圆角平滑处理，RViz 中的 `/dog_global_path` 应表现为：

1. 距离障碍物边缘更远；
2. 无意义小折线明显减少；
3. 路径点分布更加均匀；
4. 为 DWA 提供更稳定的参考方向。

### 11.2 局部路径效果

DWA 局部路径 `/dog_dwa_path` 是机器人当前真正准备执行的路径。改进后，局部路径应表现为：

1. 在开阔区域中，局部路径与 A* 参考路径方向基本一致；
2. 在障碍物附近，局部路径可根据雷达数据实时偏移；
3. 遇到墙角时，DWA 能结合后退、转向、侧移等动作生成可行局部轨迹；
4. 路径更新时不再强制机器人严格跟踪旧 A* 轨迹，而是以 DWA 当前轨迹为主。

### 11.3 机器人运动姿态

改进前，机器人在部分区域会出现大量侧向通过现象，即使头部朝前即可通过，也可能使用复杂侧移。改进后：

1. 当机器人头部与 DWA 局部路径夹角较大，且空间足够时，优先调整头部方向；
2. 对齐过程中侧向速度被压低；
3. 开阔区域中机器人更多以前向速度 `vx` 运动；
4. 侧移主要保留在墙角、窄通道和避障场景中。

### 11.4 速度变化

改进前，多次重规划后机器人速度可能逐渐下降。原因在于 DWA 动态窗口依赖 `/odom` 中的实际速度，而仿真四足机器人步态速度存在延迟和波动。改进后：

1. DWA 在安全情况下参考上一周期实际发布的速度命令；
2. 重规划成功后短时间进入快速恢复窗口；
3. 开阔直行时设置最低巡航速度；
4. DWA 评分中速度项权重提高。

因此，机器人在多次路径重规划后应能更快恢复正常前进速度。

## 13. 结果讨论

从算法结构分析，本文方法相较于传统 A* + DWA 具有以下优势：

1. 全局路径安全性更高：障碍物膨胀和安全距离软代价降低了贴墙行走概率。
2. 全局路径更平滑：转角惩罚、视线剪枝和圆角平滑减少了无意义折线。
3. 局部规划更适合四足机器人：三维速度空间能够表达前进、侧移和转向组合动作。
4. 运动姿态更自然：头部对齐机制减少了开阔空间中的侧向移动。
5. 导航连续性更好：速度保持机制减少了多次重规划后速度下降问题。
6. 安全性更高：当圆角平滑不安全时，系统自动回退到安全路径；当 DWA 不可行时，恢复策略先后退再转向，有利于墙角脱困。

同时，该方法仍存在以下限制：

1. 速度参数过高时，Gazebo 中四足步态可能出现轻微过冲或姿态不稳。
2. 在极窄通道中，过强的头部对齐可能降低通过效率，因此算法只在空间足够时启用对齐。
3. 全局地图分辨率较低时，路径平滑效果受限，可能仍会出现少量折线。
4. 实际机器人部署时，需要根据真实激光雷达噪声、地面摩擦和低层控制器性能重新调整速度上限。

## 14. 结论

本文设计了一种适用于四足机器人的全局-局部融合导航路径规划方法。该方法在全局层面改进 A* 算法，引入障碍物膨胀、安全距离软代价、转角惩罚、视线直连剪枝和安全圆角平滑，使全局路径更安全、更平滑；在局部层面改进 DWA 算法，将速度空间扩展为前向、侧向和偏航三维空间，并以 A* 路径作为参考走廊实时生成局部路径；在运动执行层面加入头部方向对齐和速度保持机制，使机器人运动更加符合四足机器人实际行走特性。

实验结果预期表明，该方法能够有效减少路径无意义弯折，降低侧向运动比例，提高多次重规划后的速度稳定性，并提升复杂室内环境中的导航流畅性和通过能力。
