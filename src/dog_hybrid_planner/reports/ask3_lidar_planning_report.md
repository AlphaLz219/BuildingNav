# ASK-3 四足机器人 Gazebo 路径规划实验报告

日期：2026-05-12

## 1. 实验目的

针对 ASK-3 四足机器人在 Gazebo 中出现四足朝上、地图尺度不匹配、fake_scan 不能代表真实雷达定位等问题，完成以下验证：

1. 修正机器人在 Gazebo 中的初始姿态和仿真站立高度。
2. 将 fake_scan 替换为部署在机器人模型上的真实 Gazebo lidar，并接入 AMCL。
3. 按《基于 ROS 的室内机器人路径规划算法研究》中的混合规划思路，验证改进 A* + DWA 在四足机器人上的可行性。
4. 在 ASK-3 适配的复杂室内地图中进行多目标导航实验。

## 2. 实验环境

- 系统：Ubuntu 20.04 + ROS Noetic + Gazebo Classic
- 机器人：ASK-3 四足机器人，base 碰撞盒 `0.39 m x 0.22 m x 0.12 m`
- 地图：`ask3_lab`，尺寸 `13.00 m x 9.50 m`，分辨率 `0.05 m/cell`
- 启动文件：`roslaunch dog_hybrid_planner dog_ask3_lab.launch`
- 结果文件：
  - `dog_hybrid_planner/experiments/results/dog_integration.json`
  - `dog_hybrid_planner/experiments/results/dog_integration_trajectory.log`

## 3. 关键修改

### 3.1 姿态与仿真稳定性

- 将 ASK-3 初始高度调整为 `z_pos=0.42`，运动学驱动固定机体高度为 `fixed_z=0.38`。
- 修正站立关节角：`HFE=-1.0`、`KFE=2.0`，避免腿部朝上导致倒置。
- 在运动学驱动中加入 `/map` 碰撞护栏：候选位置若越界或进入障碍物，则阻止平移，仅允许可行方向滑动或原地转向。

### 3.2 真实 lidar 与定位

- 在 `ask_3.urdf.xacro` 中加入 `laser` link 与固定关节。
- 使用 Gazebo ray sensor + `libgazebo_ros_laser.so` 发布 `/scan`。
- lidar 参数：`360 deg`，`720 samples`，`range_min=0.12 m`，`range_max=6.0 m`，`update_rate=12 Hz`。
- 使用 AMCL 基于 `/scan` 发布 `map -> odom`，取消默认 fake_scan。

### 3.3 算法适配

论文算法主线为：改进 A* 全局规划、关键点提取、改进 DWA 局部规划。当前实现保留该结构，并针对四足机器人做了必要适配：

- A*：双向搜索、动态权重、24 邻域搜索、三阶贝塞尔平滑。
- ASK-3 footprint：障碍物膨胀改为圆形半径膨胀，避免方形膨胀过度保守。
- 24 邻域移动：加入线段碰撞校验，避免长步长穿过障碍边缘。
- 贝塞尔平滑：平滑后再次做碰撞校验，若曲线进入膨胀障碍则回退到原始安全路径。
- DWA：由差速模型扩展为 `(vx, vy, w)` 全向速度采样，支持四足横移。
- DWA 评价：提高安全距离权重，加入制动距离约束，并使用论文中的 `cos(delta theta)` 思路抑制急转。

## 4. 实验结果

### 4.1 姿态与定位

最终仿真姿态：

- Gazebo 真实位姿：`x=1.488`，`y=6.987`，`z=0.383`
- AMCL 位姿：`x=1.600`，`y=6.738`
- 位置误差：约 `0.273 m`
- yaw 误差：约 `0.054 rad`
- 机器人未倒置，未掉出地图，机体高度保持在约 `0.38 m`

lidar 验证：

- `/scan.header.frame_id = laser`
- `/scan.range_min = 0.12`
- `/scan.range_max = 6.0`
- fake_scan 节点未运行

### 4.2 多目标导航结果

| 航段 | 目标点 `(x, y, yaw)` | 是否到达 | 用时 |
|---|---:|---:|---:|
| 1 | `(10.80, 7.30, 0.00)` | 成功 | `72.6 s` |
| 2 | `(10.80, 1.10, -1.57)` | 成功 | `36.8 s` |
| 3 | `(1.30, 7.20, 3.14)` | 成功 | `65.2 s` |

轨迹统计：

- 总实验时长：`175.5 s`
- 总轨迹长度：`40.56 m`
- 轨迹采样数：`1756`
- 平均运动速度：约 `0.231 m/s`
- 最终点：`(1.533, 6.869)`，距第三目标约 `0.405 m`，满足 `0.45 m` 到达阈值

## 5. 结论

修正后，ASK-3 能在复杂室内地图中以正常姿态运行，真实 Gazebo lidar 能稳定发布 `/scan` 并供 AMCL 定位使用。基于论文的改进 A* + DWA 混合规划框架在四足机器人上可用；加入圆形膨胀、平滑安全校验、全向 DWA、制动约束和地图护栏后，机器人能够完成三段跨区域导航实验。

后续若切换回真实步态控制而非运动学驱动，需要继续标定步态速度响应、足端摆动安全半径和实际 lidar 安装高度。
