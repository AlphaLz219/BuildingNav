# 四足机器人导航路径规划方法算法说明与实验报告

## 摘要

针对四足机器人在室内复杂环境中自主导航时存在的路径贴障、全局路径折线过多、局部避障动作不自然、多次重规划后速度下降等问题，本文在传统 A* 全局路径规划算法和传统 DWA 局部路径规划算法的基础上，结合已有改进算法与 ASK-3 四足机器人运动特性，设计了一种面向四足机器人的全局-局部融合导航路径规划方法。该方法首先保留了原始研究中对传统 A* 的双向搜索、动态权重、24 邻域扩展和贝塞尔平滑等改进；随后进一步引入机器人足迹膨胀、安全距离软代价、转角惩罚、视线直连剪枝、安全圆角平滑和路径重采样，以提升全局路径的安全性和平滑性。在局部规划方面，本文保留 DWA 算法的动态窗口、轨迹预测和多目标评价思想，并将其扩展到四足机器人三维速度空间 `(vx, vy, w)`，同时加入 A* 参考走廊约束、头部朝前优先、侧向运动抑制、重规划速度保持和恢复控制策略。实验基于 ROS、Gazebo、RViz 和 ASK-3 四足机器人仿真平台完成，用于验证所提出方法在复杂室内地图中的可行性和有效性。

## 1. 研究背景与问题分析

移动机器人路径规划通常分为全局路径规划和局部路径规划。全局路径规划基于已知地图生成从起点到目标点的整体路径，局部路径规划则根据实时传感器信息进行避障和运动控制。传统 A* 算法具有结构清晰、搜索稳定、易于在栅格地图中实现等优点，但直接应用于四足机器人时容易出现路径贴近障碍物、折线较多和拐角不平滑等问题。传统 DWA 算法具有实时性强、能够结合速度约束和障碍物信息进行局部避障等优点，但其常用于轮式机器人，默认运动模型不完全符合四足机器人的运动特性。

四足机器人相比轮式机器人具有以下特点：

1. 机体尺寸不可忽略，不能将机器人简单视为质点。
2. 机器人运动时存在机体摆动和足端支撑变化，需要更大的安全余量。
3. 四足机器人可以侧向移动，但主要运动方式仍应以头部朝前行走为主。
4. 局部避障时可以后退、侧移和转向，但在开阔区域中大量侧移会导致运动姿态不自然。
5. 仿真环境中四足步态速度和里程计反馈可能存在延迟，容易影响 DWA 动态窗口采样。

因此，本文不是简单将传统 A* 与 DWA 直接叠加，而是在保留原有改进算法优点的基础上，对全局路径生成、局部轨迹选择和四足机器人执行姿态进行综合优化。

## 2. 算法总体结构

本文算法由三层组成：

| 层级 | 作用 | 主要内容 |
| --- | --- | --- |
| 基础改进层 | 保留原本采用的改进算法 | 双向 A*、动态权重、24 邻域、贝塞尔平滑、DWA 动态窗口 |
| 四足适配层 | 使算法适配 ASK-3 四足机器人 | 足迹膨胀、三维速度空间、侧移控制、头部方向约束 |
| 融合优化层 | 提高复杂环境下的稳定性和效率 | A* 参考走廊、DWA 实时路径、速度保持、路径切换防抖、recovery |

整体流程如下：

1. 通过地图服务器发布静态栅格地图。
2. 机器人通过激光雷达和 AMCL 获得自身在地图中的位姿。
3. 改进 A* 根据起点和目标点生成全局参考路径。
4. DWA 每个控制周期基于机器人当前状态、雷达障碍点和 A* 参考走廊生成实时局部路径。
5. 导航控制层根据 DWA 轨迹方向、四足机器人头部姿态和速度保持机制发布三路速度命令。
6. `dog_sim` 中原始四足低层控制器根据速度命令生成实际四足步态。

在该框架中，A* 负责提供全局可通行方向，DWA 负责实时局部避障和实际运动轨迹生成，四足运动约束层负责使机器人运动姿态更自然、更接近实际四足机器人行为。

## 3. 传统 A* 算法及其局限性

### 3.1 传统 A* 算法原理

A* 算法是一种启发式图搜索算法。对于栅格地图中的每个节点 `n`，其评价函数为：

```text
f(n) = g(n) + h(n)
```

其中，`g(n)` 表示从起点到当前节点的实际代价，`h(n)` 表示从当前节点到目标点的启发式估计代价。传统 A* 通常采用欧氏距离或曼哈顿距离作为启发函数。

### 3.2 传统 A* 的不足

传统 A* 在四足机器人导航中存在以下不足：

1. 单向搜索在大地图中搜索范围较大，效率有限。
2. 4 邻域或 8 邻域扩展方向较少，路径容易呈现折线。
3. 只考虑路径长度，容易贴近障碍物边缘。
4. 原始路径不平滑，不利于机器人连续运动。
5. 未考虑四足机器人的机体尺寸和运动摆动余量。

因此，本文首先保留原本所采用的改进 A* 结构，再在此基础上进一步进行四足机器人适配。

## 4. 原本采用并保留的改进 A* 算法

本研究最初采用的 A* 算法并非传统 A*，而是已经包含多项改进。该部分作为本文算法基础被保留，并在后续实验中继续发挥作用。

### 4.1 双向 A* 搜索

传统 A* 从起点单向向目标点搜索。原有算法采用双向搜索策略，即从起点和目标点同时进行搜索，当两侧搜索区域相遇时完成路径构建。

双向搜索的优势在于：

1. 减少单向搜索的无效扩展区域。
2. 提高大地图中的搜索效率。
3. 在起点和目标点距离较远时更容易缩短搜索时间。

双向搜索最终路径由起点侧路径和目标侧路径拼接得到。

### 4.2 动态权重启发函数

传统 A* 的启发项权重固定，可能导致搜索效率与路径最优性之间难以平衡。原有算法引入动态权重，使评价函数变为：

```text
f(n) = g(n) + W(n) * h(n)
```

其中动态权重可表示为：

```text
W(n) = 1 + k / (2L)
```

`L` 表示起点与目标点之间的估计距离，`k` 表示当前双向搜索前沿之间的距离。搜索初期权重较大，可以加快向目标方向扩展；搜索后期权重减小，有利于保持路径质量。

### 4.3 24 邻域扩展

传统 A* 常使用 4 邻域或 8 邻域扩展。原有算法采用 24 邻域扩展，即在当前节点周围更大范围内选择候选节点。

24 邻域扩展的优点包括：

1. 增加搜索方向，使路径方向选择更丰富。
2. 减少由栅格离散化导致的锯齿路径。
3. 有利于生成更接近直线或斜线的路径。

与传统 8 邻域相比，24 邻域能够在全局搜索阶段得到更平滑的初始路径。

### 4.4 贝塞尔曲线平滑

原有算法在 A* 得到离散路径后，使用三次贝塞尔曲线对路径进行平滑处理。贝塞尔平滑能够将折线段转换为连续曲线，从而减少机器人执行路径时的突然转向。

贝塞尔曲线的一般形式为：

```text
B(t) = (1-t)^3 P0 + 3(1-t)^2 t P1 + 3(1-t)t^2 P2 + t^3 P3
```

其中 `P0`、`P1`、`P2`、`P3` 为控制点，`t` 的取值范围为 `[0, 1]`。

### 4.5 原有改进 A* 的保留价值

上述双向搜索、动态权重、24 邻域和贝塞尔平滑构成了本文全局规划的基础。相比传统 A*，该算法已经具有更高搜索效率和更好的路径连续性。因此，本文后续改进不是推翻该算法，而是在其基础上解决四足机器人导航中更具体的问题，例如路径安全距离、墙角通过性、路径过度弯折和局部执行稳定性。

## 5. 面向四足机器人的 A* 进一步改进

### 5.1 机器人足迹膨胀

传统 A* 通常将机器人视为质点，但四足机器人具有明显的机体长度和宽度。本文根据 ASK-3 机体尺寸对障碍物进行膨胀处理，使路径规划时预留机器人身体通过空间。

设障碍物膨胀半径为：

```text
r_inflate
```

若某一栅格到障碍物的距离小于 `r_inflate`，则将该栅格视为不可通行。该方法能够避免规划路径穿过机器人实际无法通过的狭窄区域。

### 5.2 24 邻域线段安全检测

24 邻域扩展虽然能减少路径折线，但长步长扩展可能出现“穿角”问题，即两个节点本身可通行，但两点之间的连线穿过障碍物边缘。为解决该问题，本文在扩展邻居时对路径段进行超采样检测，只有当前节点到候选节点之间整条线段均处于自由空间时，才允许扩展。

该改进保留了 24 邻域路径平滑的优点，同时避免了跨越障碍物边角的不安全路径。

### 5.3 安全距离软代价

硬膨胀只能保证路径不发生几何碰撞，但路径仍可能贴着膨胀边界行走。对于四足机器人而言，身体摆动和足端落点会使贴墙路径存在较高风险。因此，本文引入软安全距离代价。

设候选节点到最近障碍物的距离为 `d_obs`，安全距离半径为 `r_clear`，则软代价定义为：

```text
C_clear = w_clear * (1 - d_obs / r_clear)^2,  d_obs < r_clear
```

当节点越靠近障碍物时，代价越大；当节点距离障碍物超过安全距离半径时，该项代价为零。该策略使全局路径倾向于从走廊中部通过。

### 5.4 转角惩罚

为进一步减少 A* 路径中的无意义折线，本文在搜索阶段加入转角惩罚。设父节点、当前节点和下一候选节点分别为 `p`、`n`、`q`，对应方向向量为：

```text
v1 = n - p
v2 = q - n
```

转角代价为：

```text
C_turn = w_turn * (1 - cos(theta))
```

其中 `theta` 为 `v1` 与 `v2` 的夹角。该代价使算法在多条长度接近的路径中优先选择方向变化较少的路径。

### 5.5 视线直连剪枝

搜索得到的路径仍可能包含冗余中间节点。本文在后处理阶段进行视线直连剪枝：从当前路径点出发，寻找其后方最远且可直接连通的路径点，若两点间线段不穿过障碍物膨胀区，并满足最小安全距离要求，则删除中间路径点。

视线直连剪枝能够显著减少路径中由栅格搜索造成的局部折线。

### 5.6 安全圆角平滑与回退机制

在视线剪枝后，本文采用 Chaikin 圆角平滑方法进一步改善路径连续性。对于相邻路径点 `P_i` 和 `P_{i+1}`，生成：

```text
Q_i = 0.75 P_i + 0.25 P_{i+1}
R_i = 0.25 P_i + 0.75 P_{i+1}
```

平滑后，系统会检查新路径是否进入障碍物膨胀区。若平滑路径不安全，则放弃圆角平滑，回退到视线直连剪枝路径。因此，当终端出现：

```text
[A*] Corner smoothing unsafe; using line-of-sight shortcut path
```

表示圆角平滑可能切入障碍物膨胀区，系统主动使用更安全的直连剪枝路径。该提示不是规划失败，而是安全保护。

### 5.7 路径重采样

为了使 DWA 能稳定使用全局路径作为参考走廊，本文对最终全局路径进行固定间距重采样。重采样后的路径点分布更加均匀，有利于局部目标选取和路径方向估计。

## 6. 传统 DWA 算法及其局限性

### 6.1 传统 DWA 算法原理

DWA 算法根据机器人当前速度和加速度约束生成动态窗口，在窗口内采样多组速度，并预测短时间内的运动轨迹。每条轨迹通过评价函数打分，最终选择最优速度作为控制输出。

传统 DWA 的速度空间一般为：

```text
(v, w)
```

其中 `v` 为前向线速度，`w` 为角速度。

### 6.2 传统 DWA 评价函数

传统 DWA 常用评价函数可表示为：

```text
G(v, w) = alpha * heading(v, w)
        + beta  * dist(v, w)
        + gamma * velocity(v, w)
```

其中：

| 项目 | 含义 |
| --- | --- |
| `heading` | 轨迹终点朝向目标的程度 |
| `dist` | 轨迹与障碍物的最小距离 |
| `velocity` | 速度大小 |

该方法能够兼顾目标方向、避障安全和运动效率。

### 6.3 传统 DWA 在四足机器人中的不足

传统 DWA 面向差速轮式机器人设计，直接用于四足机器人时存在以下问题：

1. 速度空间缺少侧向速度，无法表达四足机器人侧移能力。
2. 评价函数未考虑四足机器人头部朝前运动习惯。
3. 对侧移和前进的偏好不明确，容易产生姿态不自然的运动。
4. 在墙角、窄通道中容易陷入旋转、侧移和停止反复切换。
5. 多次重规划后，里程计速度滞后可能导致动态窗口持续偏低。

因此，本文在保留 DWA 动态窗口和轨迹评价思想的基础上，对其运动模型和评价函数进行四足机器人适配。

## 7. 原本采用并保留的改进 DWA 算法

### 7.1 安全速度窗口

原有 DWA 算法中保留了动态窗口思想，并结合机器人最大加速度、最大角加速度和最大减速度约束，限制机器人在一个控制周期内能够达到的速度范围。

动态窗口为：

```text
vx_min = max(vx_lower, vx_current - a_max * dt)
vx_max = min(vx_upper, vx_current + a_max * dt)
vy_min = max(vy_lower, vy_current - a_max * dt)
vy_max = min(vy_upper, vy_current + a_max * dt)
w_min  = max(w_lower,  w_current  - alpha_max * dt)
w_max  = min(w_upper,  w_current  + alpha_max * dt)
```

该方法保证速度变化满足机器人动力学约束。

### 7.2 制动距离约束

原有算法根据制动距离判断候选速度是否安全。对于速度大小 `v`，其制动距离近似为：

```text
d_brake = v^2 / (2a_decel)
```

若机器人沿候选运动方向到障碍物的距离小于制动安全距离，则该速度候选被舍弃。该策略能够减少机器人以较高速度撞向障碍物的风险。

### 7.3 轨迹预测与碰撞检测

对于每组速度候选，算法在预测时间窗口内积分得到轨迹，并计算轨迹点到雷达障碍点的距离。若轨迹进入机器人硬碰撞半径内，则判定为不可行轨迹。

该部分保留了传统 DWA 的核心思想，即通过短时轨迹预测进行实时避障。

## 8. 面向四足机器人的 DWA 进一步改进

### 8.1 三维速度空间扩展

四足机器人具有前进、侧移和转向能力，因此本文将 DWA 速度空间由传统 `(v, w)` 扩展为：

```text
(vx, vy, w)
```

其中 `vx` 表示机体前后速度，`vy` 表示机体左右速度，`w` 表示偏航角速度。

对应运动模型为：

```text
x_{t+1} = x_t + (vx cos(theta) - vy sin(theta)) dt
y_{t+1} = y_t + (vx sin(theta) + vy cos(theta)) dt
theta_{t+1} = theta_t + w dt
```

该模型能够表达四足机器人全向运动能力。

### 8.2 进度评价替代单一朝向评价

传统 DWA 对轮式机器人常使用朝向目标的角度作为主要评价项。四足机器人可以侧移，因此仅以朝向角评价会限制其局部避障能力。本文使用轨迹终点相对于当前点到局部目标距离的减小量作为进度评价：

```text
progress = (d_start - d_end) / d_start
```

该项直接反映候选轨迹是否让机器人接近局部目标。

### 8.3 前向运动偏好

四足机器人虽然可以侧向移动，但正常行走应以头部朝前为主。本文在 DWA 评价函数中加入前向运动偏好：

```text
forward_bias = max(vx, 0) / vx_max
```

并结合侧向速度比例降低纯侧移轨迹得分。该策略使机器人在前方通道开放时优先选择前进。

### 8.4 侧向运动惩罚与侧向绕障奖励

为了避免机器人在开阔区域中无意义侧移，算法对侧向速度比例加入惩罚。但在局部目标明显位于侧方或障碍物需要绕行时，算法又保留侧向绕障奖励，使机器人仍能利用四足机器人的侧移能力。

因此，侧移不是被完全禁止，而是从“常规运动方式”调整为“局部避障和窄空间调整手段”。

### 8.5 A* 参考走廊约束

本文将 A* 生成的全局路径作为 DWA 的参考走廊。DWA 对每条预测轨迹的中点和终点计算其到全局路径局部窗口的距离，距离越近得分越高。

该策略解决了两个问题：

1. DWA 不会完全脱离全局规划方向。
2. 机器人实际执行路径仍由实时局部规划决定，避免机械跟踪 A* 导致卡顿。

### 8.6 DWA 实时路径可视化

传统导航系统通常只显示全局路径，而局部规划过程不够直观。本文将 DWA 当前最优预测轨迹发布为：

```text
/dog_dwa_path
```

同时保留 A* 全局路径：

```text
/dog_global_path
```

在 RViz 中可以同时观察 A* 全局路径和 DWA 实时局部路径，有利于分析全局规划与局部执行之间的关系。

## 9. A* 与 DWA 融合层创新

### 9.1 从“路径跟踪”到“参考走廊”

传统全局-局部规划方法通常将全局路径作为局部规划器必须跟踪的路径。本文将全局路径定义为参考走廊，而不是强制执行轨迹。DWA 根据实时障碍物信息生成实际轨迹，只需在评分上倾向于靠近 A* 参考路径。

这样既保留了全局规划的方向性，又提高了局部避障的灵活性。

### 9.2 局部目标单调推进

为了避免机器人在墙体两侧路径段之间错误切换，本文使全局路径索引沿路径单调推进。局部目标点由当前路径进度向前选取，而不是每次在整条路径上寻找欧氏距离最近点。

该策略减少了“隔墙选点”和“路径跳变”问题。

### 9.3 路径切换防抖

周期性重规划可以修正机器人偏离路径的问题，但若新旧路径差异过大，机器人可能陷入反复转向。本文在周期性重规划中加入路径切换判断：当新旧路径局部方向、横向目标位置或目标跳变过大时，暂时保留当前路径。

该策略减少了 A/B 两条路径反复切换导致的原地旋转。

### 9.4 头部方向对齐机制

当机器人头部方向与 DWA 实时路径方向夹角较大，且周围空间足够时，系统优先控制机器人头部对齐 DWA 路径方向，并降低侧向速度比例。

该机制使机器人在开阔空间中更倾向于头朝前运动，而不是以侧向姿态长距离移动。

### 9.5 重规划后速度保持机制

在 Gazebo 四足机器人仿真中，里程计速度可能滞后于速度命令，导致 DWA 动态窗口在多次重规划后倾向于低速。本文引入上一周期速度命令作为辅助速度状态，并在成功重规划后设置短时间快速恢复窗口。

该机制能够减少机器人多次规划后速度明显下降的问题。

### 9.6 Recovery 脱困策略

当 DWA 无法找到可行轨迹或机器人在障碍物附近长时间无进展时，系统进入恢复状态。恢复动作顺序为：

```text
后退 -> 小角度旋转 -> 侧步
```

该顺序适合四足机器人在墙角附近脱困，因为先后退能够为机体转向创造空间，减少原地旋转时尾部或身体侧面继续贴墙的风险。

## 10. 算法以外的系统创新

### 10.1 真实仿真激光雷达替代 fake_scan

原系统中曾使用 `fake_scan` 模拟激光雷达作用。本文在 Gazebo 机器人模型上加入真实仿真激光雷达，使机器人通过 `/scan` 获取周围障碍物信息，并用于 AMCL 定位和 DWA 局部避障。

相比 fake_scan，真实仿真雷达更接近实际部署环境。

### 10.2 激光雷达自体过滤

四足机器人机体较复杂，雷达点云中可能出现落在机器人自身范围内的点。若这些点被误认为障碍物，会影响局部规划。本文加入机身区域过滤，移除位于机器人自身矩形范围内的雷达点，减少自身障碍误识别。

### 10.3 与 dog_sim 原始低层运动控制解耦

本文路径规划层只发布三路速度命令，不直接修改四足机器人低层步态控制。低层运动仍由 `dog_sim` 原始控制器完成。这样既保留了原始四足运动代码，又能在路径规划层进行算法改进。

### 10.4 RViz 双路径显示

系统同时显示 A* 全局路径和 DWA 实时局部路径。该设计有利于实验分析：

1. 若 A* 路径不合理，可从全局路径观察。
2. 若 DWA 执行不合理，可从实时局部路径观察。
3. 若机器人实际运动与 DWA 路径不一致，可进一步分析低层步态控制或速度接口。

## 13. 实验现象与结果分析

### 13.1 全局路径变化

相比传统 A*，原有改进 A* 通过双向搜索、动态权重、24 邻域和贝塞尔平滑减少了搜索时间和路径折线。进一步加入安全距离代价、转角惩罚、视线剪枝和圆角平滑后，全局路径在 RViz 中应表现为：

1. 距离障碍物边缘更远。
2. 无意义小折线更少。
3. 路径点分布更均匀。
4. 在墙角附近保持更合理的通过空间。

### 13.2 局部路径变化

相比传统 DWA，本文 DWA 能够生成包含侧移的局部轨迹，但不会在开阔区域过度侧移。DWA 实时路径应表现为：

1. 大方向与 A* 参考路径一致。
2. 障碍物附近可实时偏移。
3. 在窄通道中保留侧移能力。
4. 在开阔区域更倾向于前进。

### 13.3 运动姿态变化

加入头部方向对齐机制后，机器人在空间充足时应先将头部转向 DWA 局部路径方向，再以前向速度通过。该方法减少了长距离侧向移动，使四足机器人运动姿态更自然。

### 13.4 速度变化

加入速度保持机制后，多次重规划后速度下降现象应明显减轻。机器人在开阔区域能够保持最低巡航速度，重规划成功后能够在短时间内恢复正常运动速度。

## 15. 本文创新点总结

本文创新点可归纳为三类。

第一，保留并应用原有全局规划改进：在传统 A* 基础上采用双向搜索、动态权重、24 邻域扩展和贝塞尔平滑，提高全局搜索效率和初始路径质量。

第二，针对四足机器人进一步改进全局规划：引入机体足迹膨胀、安全距离软代价、24 邻域线段安全检测、转角惩罚、视线直连剪枝、安全圆角平滑和路径重采样，使全局路径更加安全、平滑，并更适合四足机器人通过。

第三，针对四足机器人改进局部规划和融合机制：将 DWA 扩展到 `(vx, vy, w)` 三维速度空间，以 A* 路径作为参考走廊而非强制轨迹，加入前向运动偏好、侧向运动抑制、DWA 路径方向头部对齐、路径切换防抖、重规划速度保持和 recovery 脱困策略，提高机器人在复杂室内环境中的导航流畅性和运动自然性。

## 16. 结论

本文围绕四足机器人室内导航路径规划问题，在传统 A* 和 DWA 的基础上，保留了原有改进算法的优势，并进一步针对四足机器人机体尺寸、运动姿态和局部避障特点进行了系统优化。改进后的 A* 算法能够生成更安全、更平滑的全局参考路径；改进后的 DWA 算法能够实时生成符合四足机器人运动能力的局部路径；融合层中的头部对齐、速度保持、路径切换防抖和 recovery 策略进一步提高了导航过程的稳定性和自然性。

因此，该方法能够作为四足机器人在复杂室内环境中进行自主导航路径规划的一种可行方案，并为后续实际机器人部署和进一步算法优化提供基础。
